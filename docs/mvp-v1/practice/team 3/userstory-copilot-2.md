## User Story

**US-002**: 作為專案成員，我希望能在 Jira 儀表板上快速切換不同專案，並即時查看各專案的進度百分比與預計完成日期，以便能有效比較多個專案的狀態，協助團隊資源分配與風險控管。

### 驗收標準（Acceptance Criteria）
- 能在儀表板上選擇並切換不同專案，畫面即時更新對應專案的進度與預計完成日期。
- 每個專案皆顯示目前進度百分比與預計完成日期。
- 若任一專案進度落後，儀表板會以顏色或提示標示。
- 切換專案時，資料需於 5 秒內完成更新。

---

#### AC01: 多專案切換與即時資料更新
```gherkin
場景：專案成員切換不同專案
Given 儀表板支援多專案切換
When 使用者切換專案時
Then 畫面應於 5 秒內即時更新對應專案的進度與完成日期
And 不應顯示過時或錯誤的資料
```

#### AC02: 正確顯示各專案進度與完成日期
```gherkin
場景：專案成員查看多個專案狀態
Given 系統已正確取得所有專案的進度資料與預計完成日期
When 使用者瀏覽儀表板
Then 每個專案皆顯示目前進度百分比與預計完成日期
And 顯示數據需與資料來源一致
```

#### AC03: 進度落後時顯示警示
```gherkin
場景：專案進度落後時的視覺提醒
Given 儀表板已正確顯示專案進度
When 任一專案進度落後於預期
Then 儀表板應以顏色或提示標示該專案
And 使用者能一目了然辨識進度風險
```

### INVEST 原則檢查
- **V（Valuable）**：對專案管理與團隊協作有明確價值 ✓
- **T（Testable）**：可根據專案切換、進度顯示、提示等條件驗證 ✓
- **S（Small）**：可於一個 Sprint 內完成
- **I（Independent）**：可獨立開發
