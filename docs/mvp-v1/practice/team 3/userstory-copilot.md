## User Story

**US-001**: 作為產品經理（PM），我希望能在 Jira 儀表板上即時查看專案的整體進度與預計完成時間，以便能有效掌握專案狀態並及早調整計畫，確保專案如期完成。

### 驗收標準（Acceptance Criteria）
- 能在儀表板上清楚看到專案目前的進度百分比。
- 顯示預計完成日期，並根據進度自動更新。
- 若進度落後，儀表板會以顏色或提示標示。
- 支援多專案切換，PM 可快速檢視不同專案狀態。

---

#### AC01: 正常顯示專案進度與完成日期
```gherkin
場景：PM 於儀表板查看專案進度
Given 系統已正確取得各專案的進度資料與預計完成日期
When PM 開啟 Jira 儀表板
Then 頁面應顯示每個專案的進度百分比與預計完成日期
And 顯示數據需與資料來源一致
```

#### AC02: 進度落後時顯示警示
```gherkin
場景：專案進度落後時的視覺提醒
Given 儀表板已正確顯示專案進度
When 任一專案進度落後於預期
Then 儀表板應以顏色或提示標示該專案
And PM 能一目了然辨識進度風險
```

#### AC03: 多專案切換與資料即時更新
```gherkin
場景：PM 切換不同專案檢視
Given 儀表板支援多專案切換
When PM 切換專案時
Then 畫面應於 5 秒內即時更新對應專案的進度與完成日期
And 不應顯示過時或錯誤的資料
```

### INVEST 原則檢查
- **V（Valuable）**：對 PM 有明確專案控管價值 ✓
- **T（Testable）**：可根據進度顯示、完成時間、提示等條件驗證 ✓
- **S（Small）**：可於一個 Sprint 內完成
- **I（Independent）**：可獨立開發
