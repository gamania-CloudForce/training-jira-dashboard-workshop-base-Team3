# Jira 儀表板 User Stories 集合

## User Story #1：個人任務與專案目標關聯

**作為一位專案團隊成員，我希望在儀表板上能以視覺化方式查看個人任務與整體專案目標（Epic）的進度關聯，以便我能清楚了解自身工作對專案的貢獻與影響，從而專注於高價值任務以提升整體效率。**

---

## User Story #2：衝刺進度總覽

**作為一位工程師，我希望在儀表板上看到一個「衝刺進度總覽 (Sprint Progress Overview)」的區塊，能即時顯示目前衝刺 (Sprint) 中所有任務 (Task/Story) 的總數，並用圓餅圖或長條圖呈現不同狀態（例如：待處理、進行中、已完成）的任務數量分佈，以便我能快速掌握整個團隊的開發進度與工作負載，從而更精準地評估並調整我個人任務的 timebox，確保專案能如期推進。**

---

## User Story #3：Sprint 綜合儀表板

**作為一位專案團隊成員 (包含 PM 與工程師)，我希望有一個能即時呈現當前 Sprint 所有任務狀態、負責人與整體進度燃盡圖的視覺化儀表板，以便團隊成員能清楚地對齊任務優先級與專案目標，從而有效分配個人時間並共同確保 Sprint 能準時交付。**

---
